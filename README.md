## 📌 The Vision

In amateur youth soccer academies, daily field operations rely almost entirely on easily lost paper sheets and cluttered instant messaging groups where critical updates drown in noise. On the other hand, mainstream club management software is built for corporate accounting: heavy, slow, expensive, and impractical for coaches standing on the pitch in variable weather.

**InPanchina** bridges this operational gap focusing on two core principles:
1. **For Field Staff:** A responsive, high-speed mobile interface allowing coaches to record session attendance and behavioral assessments in under 60 seconds.
2. **For Families (Zero Friction):** Direct consultation without barriers. No store downloads, no passwords to remember: lineups, schedules, and logistics are accessed through secured, hashed links shared directly on team messaging channels.

---

## 🛠️ Planned Core Features (MVP)

- [ ] **Roster & Category Management:** Category segregation, player records, and one-tap emergency contacts.
- [ ] **One-Tap Attendance Tracker:** Streamlined on-pitch attendance states (*Present, Unexcused Absence, Excused, Injured/Modified*).
- [ ] **Developmental & Behavioral Log:** Post-session rating system evaluating effort, discipline, and sportsmanship.
- [ ] **Matchday Logistics:** Match creation, call-up rosters, gear requirements, and integrated navigation links.
- [ ] **Tokenized Parent Portal:** Zero-login view for parents accessed via unique secure URLs.

---

## 💻 Tech Architecture

* **Backend:** PHP 8.x (Object-Oriented Architecture, PDO, Prepared Statements)
* **Database:** MySQL / MariaDB (Normalized Relational Model)
* **Frontend:** HTML5, CSS3/Tailwind, Modern Vanilla JavaScript (Mobile-First responsive layout)
* **APIs:** Native Web Share API, Dynamic Map Routing
